## Theme Concept
"Light Cosmic Science" — White Scientific Canvas with Cosmic Intelligence

## Color Palette

| Token | Hex | Usage |
|-------|-----|-------|
| White | `#FFFFFF` | Primary background |
| Soft Background | `#F7F9FC` | Section backgrounds |
| Deep Blue (Primary) | `#0B5CFF` | Logo, CTAs, headings, active state |
| Electric Blue | `#1677FF` | Links, highlights |
| Indigo | `#4F46E5` | Secondary gradient stop |
| Violet | `#7C3AED` | Tertiary gradient stop |
| Cyan | `#22D3EE` | AI/technology accents |
| Premium Gold | `#D6A84F` | Very subtle luxury accents |
| Dark Text | `#111827` | Primary text |
| Secondary Text | `#64748B` | Muted text |

## Gradient System
- **Brand**: `#0B5CFF → #4F46E5`
- **Cosmic**: `#0B5CFF → #4F46E5 → #7C3AED`
- **Full**: `#0B5CFF → #4F46E5 → #7C3AED → #22D3EE`

## Typography
- **Display**: Outfit (700-900)
- **Body**: Outfit / Inter (400-600)
- **Mono**: SF Mono / Fira Code

## Visual Language
- Subtle orbital lines and rings
- Scientific grid backgrounds
- Floating data points
- Network/node patterns (very subtle)
- Number visualization as "data being analyzed"

## Design Principles
1. White canvas with generous whitespace
2. Blue-indigo-violet gradient identity
3. Scientific precision, not fortune-telling
4. Subtle cosmic elements, not full space theme
5. Apple-level simplicity
6. Premium typography and spacing
